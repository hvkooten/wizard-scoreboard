# Quickstart: Wizard Scoreboard

1. Installeer .NET SDK en MAUI workload:
   - `dotnet workload install maui`

2. Ga naar project:
   - `cd c:\Projects\wizard-scoreboard\src\scoreboard`

3. Herstel dependencies:
   - `dotnet restore`

4. Run unit tests:
   - `dotnet test --configuration Release`

5. Bouw en run:
   - Android: `dotnet build -f net8.0-android && dotnet run -f net8.0-android`
   - iOS: `dotnet build -f net8.0-ios && dotnet run -f net8.0-ios`
   - Windows: `dotnet build -f net8.0-windows && dotnet run -f net8.0-windows`

6. Controleer dashboard performance en mobiele navigatie.
